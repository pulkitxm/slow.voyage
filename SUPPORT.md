# Support

## Questions and Bugs

Use the repository's [issue forms](https://github.com/pulkitxm/slow.voyage/issues/new/choose)
for reproducible bugs, performance problems, and focused feature requests. Search
existing issues first. Include your browser and version, operating system,
device, and the settings you were driving with when they are relevant. A shared
journey link from the Journey tab helps reproduce problems at a specific spot.

The project is maintained on a best-effort basis. Response times are not
guaranteed, but clear reproductions and focused questions are easier to answer.

## Security and Conduct

Report vulnerabilities through the process in [SECURITY.md](SECURITY.md), not
through an issue. Report community conduct concerns using the private contact
guidance in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
